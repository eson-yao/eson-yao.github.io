# 姚一心 · 游戏关卡策划作品集

Next.js 静态站点，部署在 [https://eson-yao.github.io](https://eson-yao.github.io)。

## 本地开发

```powershell
npm install
npm run dev
```

打开 http://localhost:3000 。

## 构建

```powershell
npm run build
```

产物在 `out/`。推送到 `main` 后，GitHub Actions 会自动构建并发布到 GitHub Pages。

## 首次切换 Pages 发布方式

仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。
